Optional ways to check an explanation across pages. This is command reference, not a source page or a required reporting format. A thought or experience need not become an investigation.

A comment states an author's description or intention. A function name suggests a role. Neither establishes that a branch is reachable, an argument is nonzero, a calculated value is consumed, or the code is deployed. A before/after difference alone does not establish what caused it.

For an implementation claim, you may inspect the argument at the call, the definition and the later consumer together:
SELF_STUDY RELATE symbol
SELF_STUDY FIND exact_variable_or_expression
SELF_STUDY SESSION OPEN repository/caller.rs 120 | OPEN repository/helper.rs 40 | OPEN repository/caller.rs 180

Those locations are placeholders, not existing source choices. Use the exact OPEN locations returned by your own search. RELATE accepts a bare identifier or a Rust :: / Python . identifier path, up to 160 bytes, such as EventBus::new or client.publish. It supplies symbol candidates, not a resolved call graph. Qualified lookup retains the written path; it does not fall back from EventBus::new to unrelated constructors named new. Qualification, receiver/type and Self binding remain unresolved; a unique candidate in a bounded search does not settle them. Use literal FIND for other expressions, assignments, conditions and shadowing. An optional SESSION may compare distinct definition, caller and enclosing branch/loop locations; these are syntax candidates, not verified flow or execution conditions. A SESSION changes the subsequent reading position to its last selected page; retain or explicitly reselect your desired return location.

Examples of distinct questions: Is the value calculated? Is it overwritten before the consumer? Can this condition be reached for the actual argument range? Does zero disable this particular input, while another input remains active? Where is a metric defined, and what does its producer actually measure? Missing context stays missing; a familiar name such as fill is not a definition of task progress or experience.

Tests can check bounds, zero/empty inputs, rejected paths and counterexamples, but reading a test is not executing it. Source study itself runs no code. SELF_STUDY TRACE LAST inspects retained delivery/execution evidence, not unrecorded program behavior. Existing experiment commands require their own plan and authority.

An authored explanation can remain provisional. SELF_STUDY HELP notebook opens source-linked finding, counterevidence and append-only revision syntax. Inspecting contrary source does not rewrite an earlier account or resolve its inquiry. You may return, park, reread or stop without a finding.
