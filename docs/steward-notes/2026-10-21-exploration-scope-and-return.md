## Implemented Boundaries

### Expression Is Not Control

Source inspection and synthetic regressions reproduced false restrictions on
creative topics, initiation and experiment-question metadata containing words
such as control, pulse, lambda, shape and influence. The known language and
inspection handlers now bypass inherited charter/research-vocabulary rules.
Their ordinary handler, resource, privacy and capability checks remain active.
Unknown operations and actual code execution/control are not exempted.

The native dispatch regression exercises actual `CREATE`, `INITIATE`, `SELF`
and `EXPERIMENT_START` dispatch with synthetic state and a sensory channel. It
checks handling without a budget refusal or sensory-control message. It does
not call a provider or claim completed writing.

### Return Selects Context

An explicit local `EXPERIMENT_RESUME` can select a paused record even when its
saved plan is a charter, review or hold reference. Selection appends a native
paused-to-active context revision under the owner transaction. It does not run
the plan, approve control, renew a budget or reopen a held allowance. Repeating
the selection does not append another transition. Implicit START matching does
not gain this explicit-return behavior.

Retained history remains intact. Corrupt experiment history refuses return.
Concurrent returns must append only once; held allowance bytes and run history
remain unchanged. Existing partial-save receipts still report sequential
persistence truthfully; this repair does not claim atomicity for all files.

Paused history must not replace a newer unrelated stored choice. A saved plan
and a selected NEXT remain different facts, including their presentation.
Explicit return also preserves any newer NEXT rather than replacing it with
the selected experiment's historical plan.

### Repetition Is Not a Permission Check

Minime's repeated-review projection previously substituted a regulator audit
for a requested review; another cooldown discarded repeated resume NEXTs.
Both policies are retired. Old derived cue payloads cannot regain steering
authority through rendering. Projection version 12 refreshes stale derived
views; authored record schemas and historical journals are unchanged.
Explicit inspection remains metadata-only and leaves paused experiments parked.
Actual guardrail checks and REST remain in place.
Previously suppressed or substituted historical selections are not reconstructed
or replayed. Tests provide an explicitly selected current choice; they do not
infer one from older narrative or event history.

### Eligibility Has a Scope

New eligibility projections retain legacy keys and add matching Rust/Python
fields: `eligibility_scope=research_budget_creation`,
`disabled_actions_scope=this_budget_only`, and false flags for
`action_admission_evaluated`, `execution_authorized` and
`publication_evaluated`. Request/status wording explains that ordinary reading,
writing and context return do not require this allowance.

Generated request scaffolds no longer impose duplicate reading or the mere
words bind/resume/control as stopping conditions. Existing authored stop
criteria are not rewritten. Chosen hold/close, expiry, exhausted explicit
allowances, unavailable sources and concrete safety/resource/privacy failures
remain meaningful conditions. Web and consequential-action authority are
separate from allowance creation.
