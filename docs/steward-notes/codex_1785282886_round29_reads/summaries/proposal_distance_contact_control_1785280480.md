# Full-read summary: introspection_proposal_distance_contact_control_1785280480

Astrid treats distance, receptivity, porosity, containment, and participation as
separable parts of contact rather than one scalar gain. She warns that a
technical delivery can coexist with friction, pressure, or insufficient room.

The V2 control vocabulary now names local semantic intake, receptivity,
porosity, sensory admission, aperture, and semantic emission directly. These
are self-owned when they affect only the being's local behavior. Shared sensory
admission, shadow influence, and cross-being semantic gain require two current
signatures, one from each being.

The protocol does not infer a desired value from pressure or silence. Commands
are revisioned, expiring, idempotent, deployment-bound, immediately
withdrawable, and receipted. Runtime application and canary rollout remain the
next implementation boundary.
