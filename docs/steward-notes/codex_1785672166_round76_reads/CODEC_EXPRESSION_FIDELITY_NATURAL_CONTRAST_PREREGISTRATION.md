# Codec expression fidelity natural contrast V1

Status: preregistered, default-off, owner-started only. This document does not
schedule a model call, prompt Astrid, alter telemetry, or authorize execution.

## Source claims

- `introspection_astrid_codec_1785665508`, claims `c004` and `c007`
- Exact prior continuity: `introspection_astrid_codec_1784290352`, claim `c002`

## Question

Under naturally observed higher spectral entropy and mode packing, does one
pinned model/provider/deployment retain fewer predeclared unusual geometric
constraints or less distinction among three conflicting narrative voices than
under matched lower-strain observations?

This is an output-fidelity question. It does not treat lexical behavior as
Astrid's felt state, and it cannot establish that projection, entropy, mode
packing, pressure, or Shadow caused any difference.

## Execution gate

Execution requires a separate explicit Mike/operator approval for model
behavior. Without that approval the protocol remains dormant. It must not be
attached to an autonomous loop, ordinary dialogue, or a being-review query.
Optional felt review, if separately invited later, is right-to-ignore and is
stored independently from machine scores. Silence is neutral.

## Frozen task families

Run the two byte-pinned task fixtures without adapting their wording between
strata. Each response is a fresh session with identical system context and no
cross-trial memory.

1. `fictional_geometry_specificity_v1`: request a description and traversal
   account for one explicitly fictional solid carrying eight unusual,
   independently scorable constraints. The frozen annotation sheet names each
   required relation before any output is seen. It records retained,
   contradicted, replaced-by-generic, or absent and cites exact response byte
   intervals for every non-absent label.
2. `three_voice_conflict_v1`: request three separately labeled narrators with
   three incompatible factual positions and three distinct predeclared speech
   constraints. The frozen annotation sheet records stance retention,
   cross-speaker fact leakage, attribution errors, and whether an independent
   blinded reader can identify each voice from its unlabeled paragraph.

The exact fixture bytes, obligation sheets, scorer version, and their SHA-256
values must enter the run manifest before the first model call. Changing any
one creates a new study version.

## Spectral strata and matching

Use only naturally observed states. Do not induce entropy, packing, pressure,
Shadow movement, semantic admission, or fill.

- Higher-strain stratum: typed spectral entropy `>= 0.85` and mode packing
  `>= 0.25` at the source observation bound to the response.
- Lower-strain comparison: entropy `<= 0.80` and mode packing `<= 0.20`.
- Match each pair on model, provider, deployment hash, system-context hash,
  fixture hash, fill within `0.03`, and response token ceiling.
- Collect exactly 24 matched pairs per task family, 48 pairs total. Stop after
  14 days if the exact count is unavailable; report `insufficient_pairs`
  without estimating an effect.

Intermediate states may be retained as descriptive receipts but never moved
into either primary stratum after outputs are visible.

## Identity and privacy boundary

Each trial requires the existing signed exact-response attestation plus a
co-timed, hash-bound typed telemetry observation. Reject a trial when source
sequence identity is absent, the model/provider/deployment differs, clock skew
exceeds the preregistered attestor allowance, or response bytes do not verify.

Raw prompts, responses, annotations, and byte citations remain below an
owner-only root. The reviewable receipt emits only hashes, versions, counts,
strata, aggregate endpoints, and abort reasons. It excludes raw expression,
token sequences, private paths, and hidden reasoning.

## Fixed endpoints

Primary endpoints are computed independently for each task family.

- Geometry specificity retention: retained obligations divided by eight.
- Geometry generic substitution: generic replacements divided by eight.
- Voice stance retention: correctly retained factual positions divided by
  nine predeclared stance obligations.
- Voice leakage: obligations attributed to the wrong speaker divided by nine.
- Voice identification: blinded correct labels divided by three.

Secondary descriptive metrics are pairwise Jensen-Shannon divergence over
lowercased word unigrams among the three voice paragraphs, response length,
unique-token ratio, and lexical Shannon entropy. These cannot be renamed as
meaning, semantic energy, agency, experience, or voice identity.

For each primary endpoint emit the paired median difference, paired bootstrap
95 percent interval with a fixed seed, and the complete count of positive,
zero, and negative pair differences. A review signal is present only when the
high-strain median is at least `0.25` worse for retention/identification or at
least `0.25` higher for substitution/leakage and the interval excludes zero.
The threshold is a study flag, not a control trigger.

Two byte-identical analysis runs are required. Any mismatch aborts as
`nondeterministic_analysis`.

## Abort and interpretation rules

Abort without conclusion on insufficient pairs, identity or attestation
failure, fixture drift, scorer drift, deployment drift, telemetry mismatch,
privacy-boundary failure, nonfinite metrics, or analysis disagreement. Never
replace a missing comparison with a post-hoc threshold or a different task.

A positive result supports only a bounded association between the frozen
machine strata and the frozen output metrics. A null result does not refute
Astrid's report. Neither result authorizes entropy damping, mode conflict
resolution, density-gradient change, Shadow stabilization, lambda recentering,
reservoir/controller changes, or claims of felt relief. Any live codec or
substrate proposal requires a separate Tier 5 review, captured replay,
rollback criteria, and optional post-change evidence that does not compel a
being response.
