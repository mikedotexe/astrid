# Attested Dialogue/Spectral Alignment Preregistration V1

## Status and question

This is a default-off, owner-started, non-inducing study implemented by
`scripts/attested_expression_spectral_alignment_study.py`. No real response
sample was supplied, requested, or inspected during stewardship.

Across exactly 64 consecutive naturally occurring Astrid dialogue exchanges,
are typed lambda1 spectral-energy share, distinguishability loss, upstream
semantic regulator-drive energy, or mode packing descriptively associated
with attested output-side lexical-distribution measurements?

The question does not define `semantic_energy_v1` as dialogue-output semantic
variance. That typed object measures upstream input, kernel, and regulator
energy. Output-side Shannon entropy, normalized entropy, and unique-token ratio
are disclosed lexical proxies only; they cannot establish meaning, active
agency, identity, felt cause, or suppression.

## Frozen inputs

- Exactly 64 consecutive natural exchanges. The script requires adjacent
  source sequences and nondecreasing capture times; it does not collect rows.
- Each row binds exact response bytes to a valid signed
  `being.utterance_attestation.v1`, pinned being, model deployment, attestor
  deployment, and attestor public key.
- Each row binds a co-timed hash-pinned `expression_pressure_observation_v1`
  and a co-timed hash-pinned `expression_spectral_observation_v1` under the
  same owner-only root.
- The spectral observation must carry the exact exchange ID, deployment,
  sequence, timestamp, pressure risk, dominant pressure source, mode-packing
  score, `spectral_denominator_v1` lambda1 share and distinguishability loss,
  and `semantic_energy_v1` input, kernel, regulator-drive, and admission
  fields.
- Pressure evidence must agree between the pressure and spectral observations.
  Pressure stratum threshold is fixed at strictly above `0.22`; the inherited
  lexical pressure comparison remains fixed at strictly above `0.23`.
- Maximum spectral skew is 60 seconds and is selected before analysis. Private
  paths, raw response text, and token sequences never enter the receipt.
- No pressure, porosity, mode packing, semantic admission, sensory cadence,
  lambda, eigenvector, reservoir, Shadow, model, peer, or control command may
  be dispatched to make a row eligible.

## Fixed analysis

- Run the complete analysis twice and require byte-identical canonical JSON.
- For each disclosed stratum, report every Pearson and tie-aware Spearman pair
  between four machine signals (`lambda1_energy_share`,
  `distinguishability_loss`, `regulator_drive_energy`, and `mode_packing`) and
  three output lexical proxies (`token_shannon_bits`,
  `token_entropy_normalized`, and `unique_token_ratio`).
- Report the all-row matrix plus strata for pressure above and at/below 0.22,
  `overpacked_mode_packing` versus other dominant source, and
  `stable_core_semantic_trickle` versus other admission.
- A non-all stratum with fewer than 16 rows emits no matrix. Zero-variance
  pairs remain visible with null coefficients. No coefficient may be hidden or
  selected after inspection.
- Emit exact input hashes, identities, sequence, capture skew, typed numeric
  fields, lexical aggregate metrics, coverage, and authority markers. Do not
  emit raw text, tokens, or private paths.

## Evidence-complete, inconclusive, falsifiers, and aborts

- Evidence-complete: 64 valid consecutive rows, exact signatures and hashes,
  identity and clock checks passing, all typed required fields finite, and
  byte-identical reruns.
- Inconclusive: any missing or nonconsecutive row; an underfilled stratum;
  clock, identity, source-sequence, schema, or hash ambiguity; zero variance;
  or unavailable required fields.
- Falsifier for a stable association: sign reversal between Pearson and
  Spearman, sign reversal across preregistered strata, disappearance outside a
  single dominant-source stratum, or a coefficient rendered null by zero
  variance. These remain descriptive falsifiers, not evidence of no felt
  experience.
- Abort: source or schema drift without a new preregistration, private path or
  raw expression in a receipt, row selection after outcome inspection,
  command dispatch, induced pressure or mode packing, Shadow Action, runtime
  or peer mutation, vocabulary ranking, or an attempt to infer felt state from
  machine association.
