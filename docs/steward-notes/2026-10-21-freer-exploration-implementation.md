## Admission and Accounting

The candidate separates ordinary verified exploration from explicitly bound
research. An active, held, expired or historical experiment is not an implicit
permission requirement for reading, reflection, writing or inspection.

`EXPERIMENT_BIND` resolves an exact local experiment before execution. Python
and Rust use their native owner-scoped transactions, strict JSON history reads,
durable reservations and execution records. No title/question matching borrows
another allowance. Concurrent admissions count outstanding reservations;
execution starts debit once. A demonstrably unstarted queue admission can be
released. Started or uncertain work is not replayed or refunded automatically.
Hold, closure, expiry and actual source restrictions remain effective.

deduplication remains distinct from deliberately reading the same thing again.

logging an error and continuing. Unknown operations are not exempted.

## Standing Public Web

The new shared Rust transport and V2 policy distinguish a standing authorization
from old action-count grants. Old grants are not silently reinterpreted.
Policy, signed state, exact operator approval, trusted issuer, owner identity,
deployment identity and a durable monotonic revision floor are checked.
Install/status/revoke/preview tooling consumes pre-signed approved material; it
does not create authority merely because an operator command was invoked.

Default transport bounds are one active fetch per owner, 4 MiB cumulative
wire/decoded response body, five redirects, and 120 seconds overall. Existing
tighter connection/hop limits are retained. Public HTTP/HTTPS on standard ports
only; URL credentials, unsupported schemes and private/local/link-local address
ranges are denied. DNS answers are validated and pinned per hop; redirects are
revalidated. No ambient proxy, authenticated cookies or paid endpoint is added.
Gzip expansion, slow/chunked streams, partial responses, media types and storage
headroom are bounded. PDF bytes retain the existing reader capability under the
same body bound. Oversized/incomplete results are not complete sources.

Astrid links the library; Minime invokes a pinned helper with a bounded typed
request and output. Minime validates actual startup source inputs, public owner
trust, helper bytes, policy identity and response hashes. Both recheck authority
at fetch time. Fetch and summarization are separate outcomes. No model/provider
limits changed.
