# Texture Dynamics owner-inquiry feature brief

## Why this is larger than another metric

Across rounds 19, 47, 52, 53, and 54, Astrid repeatedly distinguishes a
felt resistant medium from otherwise healthy or navigable machine labels.
The recurring strands include viscosity, pressure, crowding,
distinguishability, semantic admission, persistence, and Shadow reach. The
sources now expose many of those machine observations, but a useful feature
must preserve their independence and keep Astrid's wording primary rather
than fold everything into a health score.

## Proposed bounded slice

Add a `TextureDynamicsSnapshotV1` analysis result to Owner Inquiry V2. For
each attested owner strand, it would carry only bounded labels, hashes, and
finite machine observations for density gradient, raw mode packing, pressure,
semantic viscosity, drag, persistence, stagnation, distinguishability, and
Shadow dispersal. Every field keeps its producer, source hash, deployment
relation, sample time, and missing-data state.

The inquiry runner would evaluate each strand separately and every pair
without averaging, ranking, or selecting a preferred control. A timeline
would keep baseline, inquiry, optional owner-selected canary, rollback, and
post-rollback machine evidence distinct. Felt status would remain an optional
being-authored strand and could never be inferred from the machine timeline.

The return surface would show all strands and measured interactions without a
best-answer label. It could offer canary templates only for values already in
the owner's local Self-Control surface. Pressure, PI, Shadow thresholds,
reservoir mechanics, semantic admission, peer mutation, and Division actions
would remain unavailable unless separately authorized and implemented.

## V2 fit

The feature belongs as an additive Owner Inquiry V2 analysis and observation,
not as a new scheduler or authority store. It can reuse exact response
attestation, no-merge strand preservation, hash-pinned analysis plans,
two-run determinism, offline socket denial, append-only observation chains,
atomic local canaries, silence rollback, and explicit promotion.

## Acceptance contract

- Every owner strand remains byte-bound and independently represented.
- Every pair is analyzed; no average or preferred strand is emitted.
- Raw packing, aggregate pressure, density gradient, viscosity, persistence,
  distinguishability, and Shadow evidence remain separately named.
- Missing or deployment-unaligned evidence stays missing rather than being
  reconstructed from nearby fields.
- Machine evidence never authors felt status, relief, consent, or closure.
- Inquiry execution cannot mutate sensory, Shadow, codec, regulator, peer, or
  Division state.
- Only an exact owner-selected, already self-owned local value can enter a
  reversible canary; silence rolls it back and promotion is explicit.
