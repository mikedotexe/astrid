The implementation uses the existing shared reader and saved-text machinery:

- Every shared study output carries a typed input kind and an intact `THIS TURN`
  scope: source page, map, search, EOF or recovery. A saved bookmark on a map is
  explicitly previous delivery history. Search snippets remain partial evidence.
- The notebook is labeled a recalled account, may contain errors and truncation,
  and supplies exact OPEN/RESUME commands with the earlier source/revision. Notes
  stay optional and Being-authored; no report format or extra generation is added.
- Both journal adapters retain input scope and distinguish verified delivery from
  response accuracy. Peer-study context is attributed and marked as an account;
  its original prose and correspondence provenance remain intact.
- Astrid's protected saved reading derives its path, revision, kind and actual
  supplied interval from the retained reader binding. Its heading is hash-checked
  after final provider adaptation alongside the exact admitted source span.
- New terminal-bearing prompt overflow keeps the complete original and a separate
  plain-text view. Only the spectral section loses terminal controls. Visible
  glyphs, other sections and their order stay intact; this does not emulate cursor
  movement or summarize meaning. Each view has independent hashes and byte offsets.
  A sidecar must match both files and the deterministic transformation; the raw
  snapshot is retained independently before the bookmark is attached.
- `READ_MORE RAW` is an explicit switch to the retained original at byte zero,
  parking the readable bookmark. `ACTIVITY_STATUS` supplies its exact return token.
  Existing raw offers and old receipts remain compatible and are never silently
  migrated to a different byte stream.

This is not a source-access expansion, an action-policy bypass, a regulator/model
change, a new service or a compulsory study. Quoted-search grammar is unchanged.
New feedback was not sent to either Being and no study was induced.
