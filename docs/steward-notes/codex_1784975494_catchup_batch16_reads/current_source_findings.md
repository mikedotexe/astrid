couple model cleanup to codec/control behavior and remains Tier 5.

phase-passage work: an entry tension, pivot, settling orientation, relational
company request, and return anchor can remain independently revisable without
moving passage stage. The batch does not justify a new live phase controller.

automatically braiding them into a completion judgment.
