# Self-owned phase continuity anchors

This report was read fully from disk. It identifies a serious gap between an
administrative phase card and a lived transition that remains recognizable
across later context. The implemented response is Passage Context V3:
`BIND_TRANSITION_ANCHOR`.

An owner can bind or revise an entry, pivot, settling, return, reopen, or
continuity anchor using a typed kind, typed association, bounded reference,
source reference, and append-only previous-anchor lineage. A shadow trajectory
is recorded only as temporal context unless an exact receipt exists. Anchors do
not score experience, infer mechanism, change passage stage, close a transition,
or affect any live control.
