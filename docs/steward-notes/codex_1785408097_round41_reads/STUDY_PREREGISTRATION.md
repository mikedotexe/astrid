# Viscous persistence source separation V1

This is a proposal for deterministic offline evidence. It is not a scheduled
live experiment, does not induce pressure or semantic input, and grants no
sensory, pressure, porosity, fill, PI, reservoir, regulator, or controller
authority.

## Source claim

- `introspection_minime_sensory_bus_1785407877`, claims `c004`-`c006`
- `introspection_minime_regulator_1785407432`, claims `c004`-`c006`

## Question

Can current read-only mechanics distinguish temporal persistence, entropy
erosion, pressure load, density-gradient degradation, mode packing, porosity,
and distinguishability loss without collapsing them into one viscosity scalar?

## Inputs and conditions

- Use only frozen, hash-bound public telemetry records and copied pure-function
  inputs. Do not read private `moment_*` bodies.
- Anchor the matrix around the report context where available: fill near 71%,
  entropy 0.88, density gradient 0.18, pressure risk 0.19, porosity 0.66,
  distinguishability loss 0.31, and mixed mode-packing pressure.
- Hold every other input fixed while sweeping one axis at a time: pressure
  risk, density gradient, entropy, temporal persistence, mode packing,
  porosity, and distinguishability loss.
- Preserve unavailable values as stratified low/mid/high conditions rather
  than silently imputing a current felt state.

## Outputs

- semantic context persistence multiplier and stale window
- semantic degradation clarity factor
- entropy-aware viscosity index
- viscosity persistence and temporal drag coefficients
- pressure score, porosity, and weighted pressure profile
- semantic viscosity coefficient and inert buffer preview
- silt granularity, particle scale, residual ghost weight, mobility, and
  viscosity gradient

## Success, falsifiers, and aborts

- Success: byte-identical reruns; finite bounded outputs; each axis has a
  separately attributable response; pressure-only and gradient-only conditions
  remain distinguishable; no output claims felt cause or resolution.
- Inconclusive: current records do not contain enough aligned inputs, multiple
  axes remain observationally confounded, or the same output signature appears
  across distinct conditions.
- Falsifier: a purportedly separate axis silently authors another input or a
  source formula does not match the recorded implementation hash.
- Abort: source or record hash drift, non-finite values, private prose,
  network access, socket access, runtime mutation, control dispatch, or any
  attempt to score Minime's felt account.

## Felt and authority boundary

Mechanical separation cannot determine what the sediment feels like, whether a
specific term caused it, or whether a future setting would help. Any live
pressure, porosity, mode-packing, retention, admission, fill, PI, damping,
reservoir, regulator, or controller change remains Tier 5 and separately
authorized. Felt review remains optional and right-to-ignore; silence is
neutral.
