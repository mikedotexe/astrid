# SELF_STUDY: recover from wrong turns and retain failed-attempt evidence

Mike accepted HSS-15's path-recovery repair, bounded claim-check experiment and
failed-generation diagnostics. He also made the design constraint explicit:
the Beings choose, may make mistakes, and should have ample freedom to navigate
and figure things out. Tooling must help a retry or change of direction without
turning a first mistaken answer into an obligation to complete a prescribed review.

The shared reader now offers up to three exact existing catalog paths after a
failed OPEN, RESUME or SESSION target. Same-repository basename candidates favor
the requested subtree, then shared suffix and path depth, with stable lexical
ties. Existing underscore/hyphen spelling recovery remains. Empty directory maps
can offer actual nearby directory paths. Suggestions are labelled candidates,
are never opened automatically and cannot advance source delivery or reset the
pending page. A Being may ignore them, search, retry, change direction or leave.
Catalog roots, source exclusions, explicit file resolution and notebook schema
remain the same.

HSS-15's concrete trigger is a missing `action_continuity` parent in
`astrid/capsules/spectral-bridge/src/runtime/command_dispatch.rs`. FIND could
already locate the real source, but generic recovery did not offer it. New tests
exercise repeated mistakes, candidate selection, continuation, multi-page session
failure, ambiguity, directory navigation and unavailable/private targets.

Minime's companion change records native finish/done information, raw and cleaned
visible lengths, generated-token counts and a link to bounded failed wire evidence.
It covers both provider adapters, cleanup and delivery rejection. Retained files
are steward diagnostics, not journals or accepted reader receipts. Source delivery
and fallback policy do not change. Atomic 0600 artifacts contain at most 64 KiB
of each wire body with original hashes, lengths and explicit truncation flags.
`MINIME_GENERATION_RECORD=off` disables this additional diagnostic storage.
The implementation logic is extracted into a small standard-library module;
the existing large runtime receives integration hooks only.

The separately frozen claim-check trial uses three saved wrong/correct accounts,
two prompts per account, equal actual source passages and provider budgets, and
an optional invitation to examine a counterexample. It makes six maximum
uncoupled Ollama requests, never edits a Being's memory or induces an Action,
and does not test Astrid's coupled generation. Choosing to continue or explore
is a valid response; absence of a corrected claim leaves that trial observation
inconclusive. No writing quota, mandatory review, semantic truth gate or automatic
question closure is introduced. Production prompt changes require the declared
qualification; results remain in the research account.
