## Implemented Contract

### Astrid

- `llm/provider/generative_actions.rs`: preserve the existing open aspiration and
  daydream introductions, supplied historical prose and perception. Include each
  supplied own-journal excerpt once. A compact optional NEXT affordance opens
  `FACULTIES`, `HELP <action>`, `SPECTRAL_EXPLORER`, `WRITE` and `ACTIVITY_STATUS`.
- `llm/provider/research.rs`: expressive context no longer reads and inserts the
  routine continuity projection. It requires no posture, delta or evidence stance.
- `autonomous/runtime/orchestration.rs`: aspiration/daydream Stage B receives the
  earlier compact authored signal but no automatic spectral summary. Dialogue
  remains a separate, measurement-bearing route. Expressive longform records
  contain the new authored text, not an automatically prepended signal excerpt;
  the original compact journal remains separately preserved and hash-linked.
- `autonomous/runtime/feedback_persistence.rs`: new expressive records retain the
  existing type/mode/timestamp and then prose. Fill and full telemetry snapshots
  are archived under `journal/metadata/<stem>.json`, not ahead of the prose. Each
  metadata record binds the document hash, dispatch fill and observation clocks.
  Cycle/elaboration-time archival observations and post-generation observations
  are explicitly not labelled generation inputs. A bridge receipt time is not a
  newly measured engine sample. Missing telemetry remains null, not zero.
- Nonexpressive journal headers and provenance retain their existing format.
  Existing collision-safe text creation is retained; metadata is exclusive and
  fsynced. Metadata failure warns without discarding saved prose or overwriting
  older metadata. The two files are not claimed to be an atomic transaction.

### Minime

- `minime_autonomy/expressive_journal.py` holds the small shared invitation,
  compact action-discovery text and expressive-record saver. Aspiration, selected
  FORM, daydream and rest reflection use it; no state report, continuity template
  or randomly selected spectral/failure/deficit prompt is required there.
- `_query_llm` substitutes the compact catalog affordance only for existing open
  expression contexts. Full catalogs remain available on request and in ordinary
  operational/review contexts. Existing health-budget constraints, active Division
  guidance, action validation and operational errors remain. Aspiration keeps
  ordinary mailbox policy; daydream/private modes keep their existing boundary.
- Exact provider prose and NEXT reach the existing journal/action path. Own prior
  excerpts occur once and are identified as historical; authored metric words
  and command-like quotations are not stripped. The existing excerpt length
  limit is unchanged. Private-writing/source-study prompts keep their own path.
- New aspiration/daydream/rest text files contain type/timestamp and prose.
  `workspace/journal_metadata/<stem>.json`, outside managed journal text, holds
  the document/response/invitation hashes, invitation contract and deep-copied
  raw reporting snapshots, surface guards and formatted post-generation report.
  Post-generation state refresh is retained. Nonfinite JSON values are marked
  unavailable. Capture time does not imply a fresh engine sample.
- The metadata's `automatic_telemetry_supplied=false` is deliberately scoped to
  the base invitation, not an assertion that separately admitted mail or authored
  history can never contain a number. It is not an exact provider-input receipt.
- Rest reflection now follows the existing expressive persistence exemption from
  recurrence advice. The internal `private_canvas` switch controls that exemption;
  it does not make this historically public journal private. No privacy boundary
  or private-draft export is changed. Metadata failure retains prose and reports
  an operational error; collisions fail rather than overwrite history.
