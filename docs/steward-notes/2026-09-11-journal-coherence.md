## Repairs and their limits

Fresh START and parentless BRANCH drafts have empty evidence. Existing drafts,
resume/revise/continue, parent branches and exact pending retries retain their
stored context. WRITE EVIDENCE deliberately attaches/replaces references; the bare
command clears them. There is no historical rewrite or automatic relevance classifier.

A shared response inspector retains final explicit choices and recognizes only
top-level command-shaped lines. It can explain an earlier OPEN versus final
CONTINUE and suggest a full SELF_STUDY FIND for a bare FIND. Verified delivery
carries this feedback into the next study or writing input. A choice receipt is
not proof that the host queued or executed it. FINISH receives WRITE FINISH
recovery rather than an inferred draft mutation. Private choices and notices stay
in protected writing artifacts. Forward fence scanning leaves backtick/tilde,
unclosed, blockquoted and indented examples inert.

Minime visual prompts quote the recorded description/status with recorded source,
age and capture/analysis availability. They no longer claim that a path or base64
field was delivered as direct image perception. Error-looking and command-looking
text remains available as quoted data. The neutral check-in keeps its 300-character
description cap with an explicit excerpt label; the visual reflection keeps its
existing full-description allowance. No new sensory input or filtering heuristic
is introduced. Private generation failure recovery names WRITE CONTINUE correctly.

Output ceilings, thinking, sampling, reservoir coupling and existing fallback order
are unchanged. Freedom to reread, write briefly, continue, revise or stop remains.
The recent research prompt experiments and contextual feedback remain offline.
