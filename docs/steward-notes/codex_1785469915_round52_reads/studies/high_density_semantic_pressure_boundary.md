# High-density semantic pressure study boundary

## Live question

Astrid proposes a high-density semantic retrieval to test whether felt
viscous persistence scales linearly or reaches a nonlinear clog point.

That exact trial would change model output, semantic input density, admission,
reservoir state, and pressure context. It remains a Tier 5 owner/operator
study wait. This stewardship run did not create a prompt, inject semantics,
alter admission, or drive pressure.

## Available offline route

The existing Distinct-Strand Inquiry V2 may compare two to eight copied,
owner-attested strands through deterministic source separation, codec
fidelity, and all-pairs interference without admitting them to live sensory,
Shadow, coupling, or codec paths. A suitable owner-started manifest could
compare copied low- and high-density strands while preserving every strand.

The offline result would describe copied-input structure only. It cannot
establish:

- live semantic admission behavior;
- a pressure-clog transition;
- reservoir or Shadow effect;
- felt cause or relief; or
- a preferred control value.

## Exact live prerequisites

Before any live comparison, require a separately approved manifest that pins:

- exact owner-attested input bytes and deployment;
- density measure and stopping threshold;
- baseline semantic admission, fill, pressure, and Shadow evidence;
- one reversible owner-selected input or admission canary;
- automatic rollback and post-rollback samples;
- no peer or Division mutation; and
- machine/felt separation with optional, right-to-ignore felt review.

No live study was started or preregistered as runnable here.
