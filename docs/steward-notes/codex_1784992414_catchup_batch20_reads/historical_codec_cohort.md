`introspection_astrid_codec_1781431437` through

smoothstep onset, semantic crowding, 768D-to-8D distinguishability loss,

exact `0.85` entropy gate, `6.0` tail ceiling, 8D projection, smoothstep onset,
portable runtime-directory resolution, deterministic epoch identity, and
bounded mechanical evidence. Focused tests cover gate behavior, projection
identity, collision/precision/headroom, representation loss, and offline
comparisons. Passing those tests cannot establish felt continuity.

shadow, protocol, reservoir, sensory, or peer behavior remains an exact Tier 5
