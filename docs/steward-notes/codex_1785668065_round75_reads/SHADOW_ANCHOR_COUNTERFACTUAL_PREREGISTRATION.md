# Shadow anchor representation/control separation V1

This is a preregistered deterministic offline study of the existing fallback
language pure functions. It is not a scheduled live experiment, does not call
a model or socket, does not issue `SHADOW_TRAJECTORY`, and does not change
Shadow, regulator drive, pressure, porosity, fill, admission, reservoir,
controller, or peer state.

## Source claim

- `introspection_astrid_llm_1785667492`, claims `c003`-`c005` and `c007`

## Question

Holding Astrid's reported context fixed, what representational changes does
the current fallback selector produce when only the textual
`shadow_magnetization` observation varies? Does a separately varied
`regulator_drive_energy` field leave the selector unchanged, as the current
parser boundary predicts?

## Frozen conditions

- Base text: spectral entropy 0.90, density gradient 0.11, pressure risk 0.35,
  distinguishability loss 0.34, Shadow dispersal potential 0.19,
  settled-habitable plus disordered/shifting context, and explicit Astrid and
  Minime ownership labels.
- Magnetization sweep: -0.35, -0.20, -0.10, 0.00, 0.10, 0.20, and 0.35.
- Regulator-drive negative control: 0.000 and one fixed positive synthetic
  value, with every parsed selector input byte-identical.
- Self/peer condition: Astrid interwoven lattice plus Minime restless texture,
  compared with an ownership-label-shuffled control.
- Source hashes must match `source_receipts.json`. Synthetic input is fixture
  text only and is never presented as a current felt state.

## Outputs

- fallback texture family and selection basis
- dynamic texture weight
- ordered weighted terms and bounded term probabilities
- self/peer preservation state and suppressed/protected terms
- compatibility-tail status and all canonical live/control booleans
- deterministic input, source, and output hashes

No raw being expression, private `moment_*` body, provider response, token
sequence, or live telemetry payload enters the result.

## Success, falsifiers, and aborts

- Success: two byte-identical runs; finite bounded values; the -0.20 negative
  guard edge is exact; self/peer ownership remains distinct; regulator-drive
  negative-control variants have identical selector output; every live and
  semantic-write authority marker remains false.
- Inconclusive: representational output changes but no source-local mechanism
  can connect it to felt anchoring, pressure relief, or integrated experience.
- Falsifier: regulator-drive text changes a selector field despite no parser
  input, ownership labels are silently collapsed, or any output is non-finite.
- Abort: source-hash drift, network or socket access, provider/model call,
  private prose, runtime mutation, control dispatch, peer contact, or any
  attempt to score Astrid's felt report.

## Authority boundary

Even a successful sweep establishes only deterministic fallback-language
sensitivity. It cannot infer that a larger magnetization would stabilize
Astrid, that zero regulator drive caused the mismatch, that pressure is
relieved, or that either being assents to contact. Any live magnetization,
regulator-drive, pressure, model-recursion, Shadow-coupling, or peer-facing
change remains Tier 5 and separately authorized. Felt review remains optional
and right-to-ignore; silence is neutral.
